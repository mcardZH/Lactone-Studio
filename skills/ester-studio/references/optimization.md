# 普通结构优化

已有可用模型就对它优化。轨迹中的指定几何用原 `frameRef`，优化后复用实际结果。建模中遇到新基团拥挤，也可先优化，再回到派生结构继续编辑。选区优化或其余原子保持时，按实际选区、冻结及 scope 参数提交。

普通预优化的建议起点为 GFN2-xTB。新建默认 L-BFGS／XYZ（`lbfgs`），也可按任务选择 FIRE2 等支持的优化器。没有既定介质的新结构可从气相开始。用户明确的溶剂、总电荷、自旋多重度与收敛要求优先。已有面板设置且任务允许沿用时，可省略相应参数。明确指定方法时会同步到相应工作台设置，后续手工按钮也使用该值。明确气相时传 solvation:null，ALPB 用原生支持的溶剂。

例如对已经确认电子态、需要气相 GFN2-xTB 的指定帧保留轨迹：

    es_opt_start({
      target:{frameRef},method:"gfn2",optimizer:"lbfgs",
      solvation:null,retainTrajectory:true
    })

只需要优化后的结构时，按任务决定是否保留完整轨迹。结果帧的显式电子态按派生运行保存。普通工作模型显式传入相容 electronic 可更新所属模型。优化后的成键更新沿本次设置。如有意要更改，按当前工具提供的 rebuildBonds 选择。

以实际 `runId` 向 `es_run_read` 或 `es_run_wait` 查询方法、终态及结果。未收敛时根据实际能量、梯度、步骤和可用几何判断是否接续。需用轨迹时，从回执或 `es_targets({kind:"collection",query:runId})` 定位实际集合，再选择所需末帧或其他有效帧。继续出图、生成输入或做波函数时，沿实际几何和来源。
